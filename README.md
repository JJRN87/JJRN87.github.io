# GasHunter · Web y catálogo público

Soporte, app-ads.txt y catálogo de recarga pública de la versión 16 (1.0.0-rc4).
La aplicación está firmada y pendiente de subir a la prueba cerrada; actualizar este repositorio no publica en Google Play.

La política se mantiene en https://jjrn87.github.io/politicas_privacidad_app/privacy.html .
Pages usa main y /(root). El catálogo se sirve desde raw.githubusercontent.com.

El workflow [.github/workflows/refresh-ripree.yml](.github/workflows/refresh-ripree.yml) consulta RIPREE cada día a las 03:23 UTC.
Véase [la documentación del catálogo](catalog-service/README.md) para validaciones, procedencia y límites.
Una actualización diaria no confirma ocupación, averías ni que los operadores hayan revisado los registros ese día.

Este repositorio no contiene código Android, claves de API, AAB/APK ni archivos de firma.
